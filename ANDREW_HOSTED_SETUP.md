# Voice PubMed Reader — start here

For Andrew and his son. No installation or Terminal needed.

1. On a Mac, iPhone or iPad, open Safari and go to:
   https://vpr.157-151-155-75.sslip.io
2. Enter the private access code Steve gives you and select Sign in.
3. Select Start voice and allow microphone access when asked.
4. Say “Search PubMed for…” followed by your topic.

The iPhone and iPad work with the Mac switched off. An internet connection is required.

## Try these commands

“Read the abstract.”
“Stop.”
“Repeat.”
“Next article.” / “Previous article.”
“Who are the authors?” / “What journal?” / “What is the PMID?”
“Read the full text.” If unavailable, the reader will say so and wait.
“What sections are available?” / “Go to results.”
“Keep reading.”

When finished, select End session. Saying “Stop” stops reading but leaves the microphone session open.
